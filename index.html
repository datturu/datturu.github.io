Published research

Peer-reviewed work applying deep learning to one of history's great unsolved puzzles.

Peer reviewed · 2025

Deep Learning in Archiving Indus Script and Motif Information

Journal of Computer Applications in Archaeology, Vol. 8, Issue 1, pp. 156–169

An end-to-end system that reads the undeciphered Indus Valley script from 4,000-year-old seals, identifies each seal's motif, and archives everything in a searchable database. I ran the initial experiments and built the database and the end-to-end workflow.
